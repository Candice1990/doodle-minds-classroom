LET’S HELP PIP

TEACHER ONLY · STANDALONE · 12 CHILDREN

Look. Test. Fix. Test again.

A standalone debugging lesson for ages 5–7, 12 children, 60 minutes. No earlier lesson or saved creation is required. A bug means instructions do something different from our chosen plan. It is a normal part of making things. These plans are Pip’s chosen plans; another order may be a good plan for a different party.

0–5 minMeet Pip and show his whole opening-night map. Introduce picture instructions: the computer follows them one at a time, left to right.
5–14 minLights: plan ON–OFF–ON–OFF; program ON–OFF–OFF–OFF. Children raise/lower hands as instructions execute. Predict, run all four steps, compare the actual trace with the plan. Change step 3 to ON, then run the whole program again. Notice both programs end OFF; the final state alone cannot prove a match.
14–24 minPath: plan gold dot–purple stripe–green leaf–gold dot; program gold dot–green leaf–purple stripe–gold dot. Point to the first difference after a test. Exchange steps 2 and 3 using the move arrows, then rerun. If children replace one tile first, test that partial repair before changing the next.
24–34 minDance: plan clap–wave–stamp–wave; program clap–wave–wave–wave. Everyone follows the current program, even when it differs. Change step 3 and test again. Explain evidence: “At step 3, we waved. Our plan said stamp.”
34–50 minEach child makes a four-step opening-night repair card. Choose a supplied challenge or draw a new four-step plan. Place a program below with one changed step (or swap two different neighbors). Partner predicts and executes it without spoken corrections, records the observed steps, finds the first difference, repairs and retests all four steps. Swap roles so each child takes home a tested card. Enter selected examples on screen.
50–57 minShow 2–3 repair stories. Explain intended behavior, observed behavior, change and retest. Keep the original program on paper so the fix remains visible.
57–60 minCelebrate opening night. Take the plan, original program, repair and test record home; teach the process to a family member.

Prepare

Open the three-page A4 landscape kit ↗. Page 1 per child; pages 2 and 3 per pair. Prepare pencils, reusable adhesive and precut cards. Page 2 has all three complete challenges and all vocabulary. Page 3 has enough cards for any supplied program; draw extra copies for original designs. No real electrical equipment is needed.

Support and extension

Support: choose the lights challenge, cover all but the corresponding plan/program step and offer ON/OFF cards. Extension: swap two neighboring distinct steps; fix one, test, then fix the other. Discuss why a correct final lamp state is insufficient. Keep the single focus on debugging; no new loops or conditions.

Screen operation

Run before editing the supplied challenges. Differences appear only after a complete run. Select a program step and a replacement card, or use move arrows. Reset challenge restores its supplied program. In Your repair, select a task, edit My plan or My program, and test. Changing either clears previous evidence. Run uses a frozen snapshot; navigation and edits lock until completion or Stop. Classroom pacing holds each instruction; reduced motion preserves these teaching pauses. Save requires a matching completed run and a name. Export/import preserves a local gallery of tested repairs; imported records must be retested on this device.

Sound effects default on after interaction. Pip’s greeting uses the existing recording; lesson instructions are teacher-led. Keyboard controls and symbols accompany colors.
