# 第四节：南瓜派对开场夜 · Opening Night

5–7 岁，12 人，六组伙伴，60 分钟。独立课程，无需参加前三节，也不需要之前的作品。

唯一核心概念是调试：看计划 → 预测并运行 → 比较实际结果 → 找到不同 → 修改 → 完整重测。程序里的“bug”是指执行结果与我们选定的计划不同，不是孩子做错了。每个例子都是 Pip 明确选定的计划；其他顺序可以是另一场派对的好计划。

## 课堂流程

| 时间 | 活动 |
|---|---|
| 0–5 分钟 | 认识 Pip，说明朋友们今晚来参加派对，展示灯光、小路、舞蹈的全景。介绍图卡从左到右，每次执行一步。 |
| 5–14 分钟 | 灯光计划：亮、灭、亮、灭；待修程序：亮、灭、灭、灭。先预测，全班随灯举手放下，运行后比较每一步。改第 3 步，再完整重测。两份程序最后都灭灯，说明只看最后状态还不够。 |
| 14–24 分钟 | 小路计划：金色圆点、紫色条纹、绿色叶子、金色圆点；程序把第 2、3 块互换。先运行再比较，通过左右移动交换回来。如果只替换一个位置，先测试这次修改，发现另一个不同，再修复。 |
| 24–34 分钟 | 舞蹈计划：拍手、挥手、跺脚、挥手；待修程序：拍手、挥手、挥手、挥手。孩子忠实跟着当前程序做动作，再比较，修第 3 步并重测。要求指着证据解释。 |
| 34–50 分钟 | 每个孩子制作自己的四步修复卡。可用提供的完整挑战，也可自画计划。下面放一份只改一个动作或交换两个相邻动作的程序。伙伴先预测，按卡执行，不靠作者口头纠正；记录结果、修改并完整重测。交换角色，让每个孩子都有测试过的作品。 |
| 50–57 分钟 | 展示 2–3 个修复故事：想要什么、实际发生什么、改了哪一步、怎么知道修好了。原始程序留在纸上。 |
| 57–60 分钟 | 庆祝派对开场，带走计划、原始程序、修复程序及测试记录，回家教家人。 |

## 打印和材料

打开 `print.html`，A4 横向、100% 实际大小、关闭页眉页脚。第一页每人一张；第二、三页每两人一套。准备铅笔、可重复粘贴胶点和预剪卡片。卡片有图案和英文名称，不只依赖颜色。第二页含三种完整示例及动作词汇；第三页的图卡数量支持任意一种示例。自创作品需要更多重复卡片时可自行画或额外打印。所有灯光都是纸上或屏幕模拟，无需真实电器。

作品要能被别人逐步执行和检查，装饰安排在测试之后。纸上保留修复前后，屏幕画廊只存最终匹配的计划与程序，解释修复过程时配合纸作品。

## 支持和拓展

支持：选灯光例子，每次遮住其他位置，只比较对应一步，提供亮/灭两种卡。

拓展：交换两个不同的相邻动作，改一个位置后测试，再修另一个；讨论“最后灯灭了”为什么不能证明完整程序符合计划。不要引入新条件判断或循环，也不要求学生先懂前几节。

## 网页操作

三个课堂挑战必须先完整运行一次，才开放修改。差异只在完整测试之后显示，先让孩子预测。点击位置后换卡，或按左右箭头移动；重置恢复原始挑战。

“Your repair”中可以选择任务，分别编辑计划和程序。修改任何一方都会清除旧测试证据；完成当前程序且四步全部匹配后才能命名保存。画廊保存在本机浏览器，可导出/导入备份。导入作品需在本机重新运行才可再次保存。

每次运行先暂停供预测，再逐步高亮指令、执行动画、累积实际记录。运行期间锁定编辑和导航，允许停止，重跑从第一步开始。提供慢速/课堂/较快节奏。减少动态效果设置保留教学停顿。声音默认开，点击后启用；Pip 问候沿用录音，教学由老师带读。
