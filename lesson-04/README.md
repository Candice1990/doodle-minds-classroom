# Pumpkin Party — Lesson 4: Opening Night

Open `index.html` in a browser; all assets are local. Teacher-operated English interface, ages 5–7, 12 children, 60 minutes. No prior lesson is required.

- `index.html`: interactive classroom lesson, English teacher guide, three complete debugging challenges, editable four-step plans/programs, local gallery with export/import.
- `print.html`: three-page A4 landscape repair kit. Page 1 per child; pages 2–3 per pair. Print at 100%, headers/footers off. Keep the original program visible when moving repair cards.
- `课程说明-中文.md`: Chinese lesson plan and preparation notes.

This lesson explicitly reuses the demo-class artwork/logo/greeting and lessons 1 and 3 illustration/sound/style modules. To move it to another device, copy the complete project folder with its relative directory structure. Copying only lesson-04 will omit dependencies.
